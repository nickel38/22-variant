# Эмулятор оболочки — практическая работа №1, вариант 22

Проект реализует CLI-эмулятор UNIX-подобной оболочки. Работа выполняется
последовательно по пяти этапам практического задания.

## Этап 1: REPL

Прототип поддерживает prompt на основе пользователя и hostname реальной ОС,
кавычки, раскрытие `$NAME` и `${NAME}`, команды-заглушки `ls` и `cd`, а также
`exit`. Ошибка команды выводится в stderr и не завершает следующий ввод.

Запуск:

```sh
./run.sh
./scripts/stage1_demo.sh
```

Проверка:

```sh
python3 -m unittest discover -s tests -v
```
